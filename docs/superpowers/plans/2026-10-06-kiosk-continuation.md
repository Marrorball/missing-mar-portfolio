Пользователь поручил продолжить текущий ларёк, сохранить проект, вынести стойку на улицу, расширить обзор внутри и добавить спящего рыжего кота.

1. Стойка слева от витрины, перед створкой. Отдельный крупный план со стороны улицы. Свободный задний проход, обзор комнаты и лежанки у обогревателя, кнопка выхода из комнаты.
2. Обложки из существующего контента, общая текстура для копий одного проекта. Название, год и категория при отсутствии изображения. Модель кота создаётся в существующем конвейере Blender, без замены сцены растровой картинкой.
3. Анимация выбранного диска к плееру; настоящий поворот ламелей перед показом страницы. Прерывание при новой навигации и мгновенное завершение для reduced-motion.
4. Проверка настольной и мобильной версии, крупных точек нажатия, клавиатуры, резервного режима, бюджета модели и всех существующих тестов. Локальный предпросмотр. Публикация требует отдельного разрешения пользователя.

Проверка: npm test, npm run validate:content, npm run build; браузер 1440×900 и 390×844, вход/выход, стойка и её стороны, диски, телевизор, билборд, контакты.

## Ход работы

- Исходное состояние: чистая ветка build/y2k-portfolio. Чат Claude прочитан в приложении; его список оставшихся задач совпадает с сохранённой спецификацией.
- Готово: стойка вынесена перед левой створкой, скамья освобождает её обзор; прилавок и стул оставляют проход внутри. Рыжий кот свернулся на пледе у обогревателя. Новый ракурс комнаты показывает пол и телевизор; доступны кнопка «Внутрь» и выход через Esc.
- Готово: обложки всех семи проектов и копий на витрине, из локальных изображений кейсов либо печатного названия. Используются общие текстуры для одного проекта.
- Готово: круглый DVD летит в плеер; 24 трёхгранные ламели переключают рекламу, «Обо мне» и прайс. Reduced-motion пропускает перелёты и повороты.
- Готово: мобильная композиция, кнопки от 44 px, более дешёвое разрешение рендера, отмена прерванного жеста. Режим без WebGL позволяет открывать все проекты и возвращаться к списку.
- Независимый review выявил два P2. Прямой #about мог создавать NaN у 24 ламелей: воспроизведено без исправления, исправлено откладыванием анимации до появления ламелей. Resize 1440×900 → 900×900 оставлял FOV 40: воспроизведено, исправлено проверкой FOV перед early return. Оба сценария включены в browser-check.js и прошли после исправления.
- Проверка: npm test — 73 JS и 9 Python; validate:content — семь проектов и две страницы; npm run build — успешно (обычное предупреждение Vite о размере three.js chunk).
- Браузер: 18 сценариев прошли на 1440×900 и 390×844, плюс три проверки fallback без WebGL. Скриншоты в docs/superpowers/qa/kiosk-continuation/. Скрипт повторного прохода — scripts/kiosk/browser-check.js.
