## Что проверено

Playwright (Chromium), размер окна задаётся вручную; касания — синтетические `PointerEvent` с `pointerType: 'touch'`. Это эмуляция, не настоящий iPhone.

- 390×844, 320×568, 844×390: телепрограмма, проект, «Обо мне», прайс на билборде, прайс на ставне, листовка и терминал раскрываются на всё окно, горизонтальной прокрутки нет, нижнее меню спрятано.
- Вкладки «Обо мне» ↔ «Прайс» на раскрытом билборде: экран остаётся открытым.
- «← НАЗАД» на телевизоре, бумажная «Назад» и серая «◀ Назад» терминала сворачивают экран и возвращают туда, откуда пришёл (на улицу — с меню).
- Свайп влево по телевизору: ПИК → Учи.ру. Вертикальная прокрутка канал не меняет.
- Переход с раскрытого билборда на проект: билборд сворачивается, камера идёт к телевизору, телевизор раскрывается.
- Поворот 390×844 → 844×390 с раскрытым экраном: остаётся раскрытым, камера на правильном расстоянии; обратно на 1280×720 — сворачивается, страница на билборде 948×474, как раньше.
- Вертушка: обложки 85×119 px на 390×844 (было ~25 px), 55 px на 320×568. Касание по обложке открывает проект на телевизоре.
- Улица на телефоне стоя: билборд над вывеской, ларёк с вертушкой на всю ширину, витрина 191 px (было ~135 px).
- 820×1180 и 1280×720: нырка нет, страницы на экранах в сцене, вертушка в прежнем кадре.
- Консоль без ошибок. `npm test`: 138 из 138.

## Найдено и исправлено по ходу

- На 320 px карточки кейса в два столбца и заголовок «ТЕЛЕПРОГРАММА» вылезали по ширине — для раскрытого экрана теперь один столбец, заголовок по ширине экрана.
- Пока экран раскрыт, нижнее меню спрятано и не имеет размеров; кадр для экрана считал его верх нулём и отводил камеру на 24 м. Теперь берётся обычное место меню.
- У терминала было две кнопки «Назад» — осталась своя, серая.
