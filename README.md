# missing mar — портфолио

Y2K-портфолио Марата Дреева. Первый экран — сцена с монументом на холме, ниже
страница уходит под землю: проекты лежат слоями в разрезе почвы.

Содержимое правится двумя способами: локальной админкой (быстрее, работает
офлайн) и Pages CMS через GitHub (можно с телефона).

## Локальная админка

```bash
npm install
npm run dev
```

Сайт — <http://localhost:5173/missing-mar-portfolio/>, админка — <http://localhost:5173/admin/>.

В админке: список проектов, добавление и удаление, обложка и картинки в разделы
кейса (загружаются в `assets/media/projects/<id>/uploads/`), поля «Обо мне» и
контакты. Кнопка «Сохранить» пишет прямо в `content/*.json`; перед записью весь
контент проверяется, поэтому сломать сайт неудачной правкой нельзя.

Админка живёт только в dev-сервере: на GitHub Pages её нет и быть не может —
там нет файловой системы, куда писать.

После правок:

```bash
npm run validate:content
git add -A && git commit -m "content: ..." && git push
```

## Графика первого экрана

Сцена собирается кодом из чистых исходников, а не догенерируется поверх
предыдущей картинки — поэтому качество не деградирует от правки к правке:

```bash
npm run build:art
```

`scripts/build-hero.py` вырезает фигуру из оригинального фото по маске Vision,
рисует стикерную обводку, кладёт её на каменную плиту и вставляет плиту в
пейзаж с контактной тенью и травой перед основанием.
`scripts/build-underground.py` нарезает из той же графики камень, почву и
кромку дёрна для нижней части страницы.

## Как открыть панель

1. Откройте [Pages CMS](https://app.pagescms.org/).
2. Войдите через GitHub-аккаунт, которому принадлежит репозиторий `Marrorball/missing-mar-portfolio`.
3. Выберите репозиторий `Marrorball/missing-mar-portfolio` и ветку `main`.
4. Откройте нужный раздел:
   - «Проекты»;
   - «Страницы»;
   - «Резюме»;
   - «Настройки сайта».
5. Измените поля и нажмите сохранение. Pages CMS запишет изменения в GitHub.
6. Подождите несколько минут, пока GitHub Pages обновит сайт.

Пароль или ключ GitHub не вводится в самом портфолио. Возможность сохранять изменения определяется правами GitHub на репозиторий.

## Как управлять проектами

- Новый проект добавляется кнопкой добавления в разделе «Проекты».
- Поле «Порядок» управляет расположением карточки: меньшие числа показываются раньше.
- Переключатель «Показывать на первом экране» и поле порядка выбирают три главных проекта.
- Переключатель «Опубликован» скрывает проект с сайта без удаления.
- Разделы кейса можно добавлять, удалять и менять местами.
- Изображения загружаются через медиабиблиотеку панели.
- Удалённый проект можно восстановить через историю GitHub.

Важно: репозиторий публичный, поэтому скрытый проект не отображается на сайте, но его исходные данные всё ещё доступны в GitHub. Не храните в контенте конфиденциальные материалы.

## Локальная проверка

```bash
npm test
npm run validate:content
python3 -m http.server 4173
```

Статический сервер отдаёт репозиторий как есть — так же, как GitHub Pages.

Для сайта, опубликованного как GitHub Project Pages, пути изображений начинаются с `/missing-mar-portfolio/`.
